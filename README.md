# wayne
Personal AI assisstance

In order to run this, here are the minimum system requirements.

As of production, this is only usable on Windows due to its use of certain libraries.

- At least 256GB of storage
- 8-16GB of RAM
- At least a Intel Core i5-6500 or Ryzen 5 5600
- Integrated Graphics works, but a GPU can be any with good VRAM
